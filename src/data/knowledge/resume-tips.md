# Technical Resume Best Practices & ATS Optimization Guide

To maximize ATS pass rates and impress senior technical screeners, structure your resume according to these proven engineering standards:

## Essential Rules

1. **Format**: Use clean, single-column layout without graphical bars, text boxes, or embedded images.
2. **Quantified Metrics**: Express impact with clear metrics. Example: _"Optimized database queries with Prisma indexes, reducing p99 latency from 450ms to 65ms."_
3. **Keyword Alignment**: Include explicit technology keywords match for your target role:
   - **Frontend**: Next.js, React 19, TypeScript, Tailwind CSS, Web Vitals, Zustand.
   - **Backend & AI**: Node.js, Python, PostgreSQL, Prisma, LLMs, Gemini, Ollama, Vector Databases, RAG.
4. **Project Highlights**: Include GitHub links, live demo URLs, and architectural highlights for all key projects.
