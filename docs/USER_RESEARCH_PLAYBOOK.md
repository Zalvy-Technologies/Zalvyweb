# USER RESEARCH PLAYBOOK
Date: 2026-09-15

## Purpose
Provide lightweight framework for gathering qualitative insight without intruding on users.

## Research Pipeline
Recruit -> Ask -> Observe -> Synthesize -> Prioritize

## Recruit
Target: visitors to high-value pages, existing users, prospects
Method: optional email invite, voluntary interviews

## Core Questions
1. What did you think ZALVY does?
2. What problem were you hoping it would solve?
3. What caught your attention?
4. What was confusing?
5. What information was missing?
6. What would make you trust ZALVY?
7. What would make you try it?
8. What would stop you?
9. What alternative would you use?
10. What would you expect next?

## Synthesis Framework
Observation -> Evidence -> User problem -> Hypothesis -> Potential solution -> Expected impact -> Priority

## Privacy
No PII required, optional consent, no recording without permission
